# Personal Portfolio

Live Demo: https://gayangidevindi.github.io/

## About

Personal portfolio for Gayangi Devindi, an Information Technology undergraduate at the University of Moratuwa focused on full-stack development, cloud technologies, AI integrations, IoT, and UI/UX design.

## Features

- Responsive single-page portfolio with dark and orange visual identity
- Professional hero, skills, education, experience, achievements, writing, projects, and contact sections
- Filterable project portfolio with accessible keyboard navigation
- Detailed MediCareX project modal with contribution, architecture, and technical challenges
- CV download and verified external profile links
- Mobile navigation, smooth scrolling, and scroll progress feedback

## Tech Stack

- React 19
- Tailwind CSS 3
- React Icons and Lucide React
- Create React App
- Jest and React Testing Library
- GitHub Pages deployment

## Featured Project — MediCareX

MediCareX is a multi-role online pharmacy and pharmacy supply-chain management platform for customers, pharmacists, suppliers, and administrators.

The project uses React, NestJS, Firebase Authentication, Cloud Firestore, Groq, Pinecone, and PayHere, with web and mobile interfaces for its connected workflows.

Live Demo: https://innovatexuom.vercel.app

## Installation

```bash
npm install
```

## Development

```bash
npm start
```

The development server runs at http://localhost:3000.

## Build

```bash
npm run build
```

## Deployment

The site is configured for GitHub Pages:

```bash
npm run build
npx gh-pages -d build
```

The `homepage` value in `package.json` points to the live portfolio URL.

## Project Structure

```text
public/              Static HTML, manifest, and metadata
src/components/      Shared layout and profile components
src/pages/           Home, projects, project details, and contact sections
src/assets/          Images, CV, and portfolio media
src/App.js           Single-page application shell
src/index.css        Global styles and Tailwind entry point
```
